#  Amity University Enquiry Chatbot (LLM + RAG)

An AI-powered chatbot that answers queries about Amity University by reading directly from the university brochure using **Retrieval-Augmented Generation (RAG)**.

##  Features
- Reads and understands the **Amity University brochure (PDF)**
- Answers questions about **courses, admissions, hostels, placements**, and more
- Built using **Hugging Face LLM (Flan-T5)** and **FAISS** for retrieval
- Interactive web interface powered by **Streamlit**

##  Tech Stack
- **Python**
- **Streamlit**
- **Transformers (Flan-T5)**
- **Sentence Transformers**
- **FAISS**
- **PyPDF2**
